# Treseko Community documentation

<!-- Language: en -->

> Español: [Documentación en español](../README.md)

This documentation helps you install Treseko, organize QA work and
administer the platform. Each guide explains which feature is available, how to
use it and what to check if something does not behave as expected.

## Getting started

1. [Quick installation](INSTALLATION.md): install Treseko with Docker or from your machine via SSH.
2. [Docker guide](DOCKER_GUIDE.md): set up a persistent installation.
3. [Access, users and permissions](AUTH_RBAC_GUIDE.md): create the first users and roles.
4. [Suite and case portability](CASE_PORTABILITY.md): import or export your cases.
5. [Linux installation](LINUX_SETUP.md): prepare a Linux installation step by step.
