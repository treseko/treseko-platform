# Treseko Community screenshots

Español: [Galería en español](README.md)

These screenshots show reference flows from Treseko Community 1.0.4 with synthetic data. They contain no credentials or operational data. Visible names, UUIDs, test email addresses and loopback URLs belong to the demo environment and must not be reused as real configuration. For current test formats, execution and evidence behavior, see the guides linked from the [English documentation index](../docs/en/README.md). Select an image to view it at full size.
